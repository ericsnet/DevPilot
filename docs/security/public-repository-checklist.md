# Public repository checklist

Before publication:
- [ ] Review every file for public disclosure.
- [ ] Scan the full Git history for secrets.
- [ ] Confirm .env and credentials are ignored.
- [ ] Review dependencies and their licenses.
- [ ] Review fonts, icons, images, and assets for usage rights.
- [ ] Confirm proprietary rights notice is present.
- [ ] Never publish OAuth secrets or provider API keys.
- [ ] Configure CI with least-privilege permissions.
- [ ] Enable secret scanning and dependency alerts where available.
- [ ] Review repository settings before making it public.

A public repository without an open-source license does not grant open-source permissions. This checklist is not legal advice.
